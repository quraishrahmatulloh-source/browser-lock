Minimal 8 karakter. Password disimpan sebagai hash di komputer lo, tidak pernah dikirim ke mana pun dan tidak bisa dilihat siapa pun, termasuk gua.

Simpan kode pemulihan

Kalau lo lupa password, kode ini satu-satunya cara masuk lagi tanpa menghapus ekstensi. Tampil sekali saja. Simpan di password manager atau catat di kertas.

⏱Kunci otomatis

Chrome selalu terkunci saat dibuka ulang. Kunci cepat: Ctrl Shift L (Mac: ⌘ Shift L). Ubah di chrome://extensions/shortcuts.

🔑Ganti password

🆘Kode pemulihan baru

Bikin kode baru. Kode lama langsung tidak berlaku.

⚠Batasan yang perlu lo tahu

  • Ekstensi bisa dimatikan atau dihapus lewat chrome://extensions. Browser Lock menutup tab, bukan pengaman tingkat sistem. Untuk komputer bersama, tambahkan kunci layar komputer.
  • Incognito dan profil Chrome lain tidak tercakup. Untuk Incognito, aktifkan Izinkan di Incognito di detail ekstensi, dan pasang ekstensi ini di tiap profil.
  • Lupa password dan kode pemulihan: satu-satunya jalan menghapus ekstensi dan memasangnya lagi.
